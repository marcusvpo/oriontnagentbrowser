#### Descrição:
Permite incluir uma nova rubrica contábil no plano financeiro do Orion TN, estipulando seu sentido financeiro (aporte de receita ou desembolso de despesa), sigla mnemônica e regras de depósito prévio.

#### Passo a passo revisado:
1. Acesse o menu **Configurações > Cadastros auxiliares > Tipo de movimentação financeira** e clique no botão **Adicionar**.
   [aqui vai a print "passo-01.png"]
   [aqui vai a print "passo-01-b.png"]
   > [!NOTE] **Demarcações na print:** (1) **Configurações** · (2) **Cadastros auxiliares** · (3) **Tipo de movimentação financeira** · (4) **Adicionar**
   > [!NOTE] **Divergência de caminho de menu (Auto-Cura de Rota):** O manual documentava o caminho **"Administração > Financeiro > Tipos de movimentação financeira"**, porém na versão atual do Orion TN a tela fica em **"Configurações > Cadastros auxiliares > Tipo de movimentação financeira"** (confiança: 91% — Rota comprovada numa auditoria anterior e reconfirmada na árvore de navegação real desta execução).
2. No campo **Descrição**, digite a denominação clara da operação (ex: 'Adiantamento de Despesas de Certidões', 'Devolução de Depósito Prévio Excedente').
   [aqui vai a print "passo-02.png"]
3. No campo **Sigla**, insira um código abreviado de até 5 caracteres (ex: `DEP`, `DEV`, `DILIG`).
   [aqui vai a print "passo-03.png"]
4. Selecione o **Tipo lançamento**: escolha **Crédito** (para entradas de recursos) ou **Débito** (para saídas/despesas).
   [aqui vai a print "passo-04.png"]
   > [!NOTE] **Divergência de rótulo (Auto-Cura SmartLocator, dom_synonym_heuristic):** O manual cita **"Tipo de Lançamento"**, porém na tela atual do Orion TN o elemento se chama **"Tipo lançamento"** (confiança: 90% — Sinônimo contextual da rota #/tipoMovimentacaoFinanceira/cadastrar: tela 102 (modal:Adicionar) tem o único campo de natureza do lançamento como "Tipo lançamento" (Raio-X de M-65.0, Fase 4; "Tipo de movimentação" é outro campo)).
5. Caso a operação seja utilizada para registrar adiantamento de clientes em escrituras, marque a opção **Depósito Prévio**.
   [aqui vai a print "passo-05.png"]
6. Clique no botão **Concluir** para registrar a nova modalidade.
   [aqui vai a print "passo-06.png"]
