#### Descrição:
Permite emitir relatórios impressos discriminando todos os atos que já foram transmitidos com sucesso ao SISCOAF, bem como a relação de atos indicados que ainda aguardam transmissão pela serventia.

#### Passo a passo revisado:
1. Acesse o caminho: **Administração > Comunicações > COAF**.
   [aqui vai a print "passo-01.png"]
   > [!NOTE] **Demarcações na print:** (1) **Administração** · (2) **Comunicações** · (3) **COAF**
   > [!NOTE] **Tela sem dados (Evidência de Tela):** grade vazia (Protocolo, Natureza, Data de lavratura, Data comunicação, Data cancelamento, Nº Ocorrência).
2. No campo **Situação do protocolo**, selecione o filtro desejado:
   [aqui vai a print "passo-02.png"]
   > [!NOTE] **Divergência de rótulo (Auto-Cura SmartLocator, a11y_fuzzy_match):** O manual cita **""Situação do protocolo""**, porém na tela atual do Orion TN o elemento se chama **"Situação do protocolo"** (confiança: 95% — Rótulo visível na tela equivalente por inclusão de nome (95%)).
   > [!NOTE] **Tela sem dados (Evidência de Tela):** grade vazia (Protocolo, Natureza, Data de lavratura, Data comunicação, Data cancelamento, Nº Ocorrência).
   * **Comunicados:** Para listar os atos já transmitidos e aceitos pelo COAF.
   * **Não comunicado:** Para listar os atos com comunicação pendente de envio.
3. Defina o período de pesquisa do ato e clique no botão **Filtrar**.
   [aqui vai a print "passo-03.png"]
   > [!NOTE] **Tela sem dados (Evidência de Tela):** grade vazia (Protocolo, Natureza, Data de lavratura, Data comunicação, Data cancelamento, Nº Ocorrência).
4. Clique no botão **Imprimir** no canto superior da tela e escolha o modelo de relatório disponível.
   [aqui vai a print "passo-04.png"]
5. Confirme a geração para que o sistema exiba o documento em formato para impressão e arquivo fiscal.
   [aqui vai a print "passo-05.png"]

* **Comunicados: Para listar os atos já transmitidos e aceitos pelo COAF.**
* **Não comunicado: Para listar os atos com comunicação pendente de envio.**
* **Importante: Esse relatório serve de comprovação oficial de conformidade com o Provimento CNJ nº 88/2019 em correições judiciais.**
* **Dica / Caso Real do 0800: Evite o uso de aspas duplas, apóstrofos e quebras de linha manuais em campos de observações para comunicações com SISCOAF e CENSEC, prevenindo rejeições de schema XML.**
