Olá! Neste vídeo, eu vou mostrar para você como realizar o cadastro completo de um orçamento de escritura e procuração. Para isso, basta clicar no menu de Notas e na opção de "Orçamento Completo". Nessa tela, os orçamentos realizados serão cadastrados no sistema, de modo que você consiga fazer a busca dos mesmos posteriormente e gerar um ato ou um protocolo a partir desses orçamentos que ficarão aqui registrados.

Nessa tela, os campos que possuem um asterisco são obrigatórios, de modo que, se você não os preencher, ao final do orçamento — na opção de "Concluir" —, você não conseguirá concluir o orçamento sem preenchê-los.

Se você preencher aqui a espécie, ela estará condicionando o campo da natureza. Por exemplo: se eu colocar a espécie de escritura, você terá à disposição os tipos de escritura para cadastrar o orçamento aqui no seu **Cartório**. Se você colocar uma espécie de procuração, serão listadas no campo da natureza apenas as procurações disponíveis para o cadastro desse orçamento.

Vamos fazer aqui, então, um orçamento completo, por exemplo, de uma escritura de compra e venda. O escrevente já estará preenchido automaticamente com base no último orçamento realizado nesta máquina. Você terá a possibilidade de colocar o CPF ou CNPJ do solicitante que está solicitando este orçamento aqui no **Cartório**. Este campo — pelo menos o nome do solicitante — é obrigatório para que você consiga fazer essas buscas posteriormente.

Repare que, ao lado desses campos, como o do CPF do solicitante, você terá uma lupa. Esta lupa segue um padrão no sistema para você reaproveitar dados de um cadastro anterior. De qualquer parte do sistema onde é realizado um cadastro de pessoa, você poderá reaproveitar as informações — como, por exemplo, o documento e até mesmo o nome do solicitante e os seus dados de contato, como telefone, e-mail e endereços, que são opcionais e facultativos aqui para o orçamento completo. Mas, se eles já estiverem em algum cadastro que você está aproveitando, serão preenchidos automaticamente. Este preenchimento é apenas uma sugestão; você poderá alterar as sugestões que o sistema trouxer para você.

Então, por exemplo, se eu colocar aqui o solicitante Ricardo e clicar na lupa, o sistema vai trazer para mim as opções que eu tenho para reaproveitamento dos dados de Ricardo, que foi o que digitei no campo de solicitante. Ele pode aproveitar os dados de um cadastro de solicitante feito anteriormente — por isso está aqui a opção de "solicitante" entre parênteses — ou posso reaproveitar os dados de um protocolo feito anteriormente. O sistema sempre vai listar o último protocolo ou o último solicitante cadastrado. Ele poderá aproveitar os dados também do último cadastro de tomadores — que é o cadastro da Nota Fiscal Eletrônica —, assim como reaproveitar os dados do último cartão de assinatura feito para essa pessoa.

Após selecionar o solicitante na opção desejada, o sistema já vai carregar as informações. Se lá, por exemplo, no cartão de assinatura desse nome que acabei de selecionar já constarem todos os dados de contato, ele já trará tudo preenchido aqui na tela. E você poderá alterar essas informações, apesar da sugestão que está sendo feita.

A tela do cadastro completo de orçamento já sugere que você selecione o ato ou a natureza das custas desejada. Para colocar a natureza desejada, você pode digitar a natureza que quer e o sistema já vai sugeri-la na barra de rolagem abaixo para você selecionar. Ou, se preferir, pode deixar em branco o campo do item e pressionar Tab no seu teclado; aí o sistema vai listar todas as naturezas disponíveis, de modo que você pode dar um duplo clique e selecionar a natureza que desejar aqui também.

Vamos trabalhar aqui com uma escritura com valor declarado para esse orçamento completo. Perceba que o sistema já permite que você coloque a quantidade de cálculos que deseja fazer no orçamento, assim como o cálculo ou o tipo de cálculo que quer colocar — por exemplo, o integral, onde ele vai calcular o valor integral das custas; o valor de diligência, onde ele vai dobrar o valor das custas; um terço, que vai calcular um terço dos valores das custas; e assim sucessivamente. Vamos trabalhar aqui com o valor integral.

Aqui no cadastro completo do orçamento, você terá a opção de informar o valor venal e o valor do instrumento. Ao digitar o valor venal e sendo, por exemplo, o valor do instrumento maior do que o valor venal, perceba que o sistema já trará para a base de cálculo o maior valor entre eles — entre o valor venal e o valor de instrumento, ele já trará automaticamente para a base de cálculo. Nada impede que você faça a digitação manual desse valor-base de cálculo, apesar da sugestão feita aqui. E aí, parcialmente, o sistema já traz para você o valor do ato notarial com base no valor-base de cálculo informado.

Você terá a opção também no seu **Cartório** de deixar uma cidade padrão para que o sistema traga uma alíquota padrão: ao digitar essa cidade, o sistema já trará a alíquota padrão, ou você pode digitar a alíquota e o sistema já vai calcular para você. Tanto o valor-base de cálculo para o ITBI já pode vir com alíquota padrão ou você pode digitá-la, como também o valor de registro já vem com o valor padrão do Registro de Imóveis, com base no valor-base de cálculo digitado aqui.

Você vê que esse valor sugerido aqui é apenas o valor de registro. Se você desejar adicionar a esse valor outros valores além do Registro de Imóveis, como o valor de prenotação ou de certidões, poderá fazer uso da tabela do Registro de Imóveis, que é este ícone de cifrão ($) aqui do lado. Ao clicar nesse cifrão, o sistema abrirá uma nova tela onde você poderá adicionar os valores de certidão do registro, já trazendo como padrão o valor de certidões. Você pode colocar, por exemplo, duas certidões que quer adicionar ao seu cálculo, e ele já traz o valor. Você pode alterar a cidade e o percentual aqui, que o sistema já calculará, de acordo com a cidade e o percentual do ISS, o valor para aquela natureza do Registro de Imóveis desejada.

Se você quiser acrescentar outros valores, como por exemplo uma averbação, basta clicar no sinal de mais (+) para adicionar um ato. Aqui você digita o código (se já souber o item) ou digita a descrição (se não souber), e o sistema já vai trazer, por exemplo, uma averbação com valor declarado, onde você já tem o valor preenchido e pode trabalhar com a quantidade também. Se quiser adicionar o valor de prenotação também, o sistema já vai trazer para você o valor da prenotação.

E aqui ele já fez, com base na tabela do Registro de Imóveis, todo o cálculo do registro, trazendo um panorama para você. Quando você clicar em "Concluir", o sistema vai avisar que a soma desses valores é diferente da soma que já existia naquele campo do Registro de Imóveis e perguntará se você quer atualizar o valor. Ao confirmar que sim, ele já trará o valor que você calculou lá.
