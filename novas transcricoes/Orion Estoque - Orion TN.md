Olá, pessoal! Hoje eu venho fazer a demonstração do módulo **ORION Estoque**. O módulo **ORION Estoque** fica integrado dentro do sistema **ORION TN**. Então, a gente vai acessar aqui através de um link no meu navegador de preferência, no meu site de acesso. Vou utilizar aqui o meu usuário e senha e, ao realizar o acesso, o sistema me mostra os módulos que eu tenho liberados no meu perfil, com as permissões a que tenho acesso. Então, vou acessar aqui o módulo **Estoque**. Assim como os outros módulos, o **Estoque** tem um visual bem limpo, com fácil visualização e uma dinâmica tranquila de se trabalhar. É um sistema bem intuitivo, bem tranquilo de se trabalhar.

Aqui eu tenho dois menus superiores. Vou até aumentar um pouco o zoom aqui para ficar melhor a visualização. Essa é uma das facilidades de se utilizar o sistema web: eu consigo ajustar a visualização do jeito que desejo; então, consigo aumentar o tamanho ou diminuir para se enquadrar melhor no monitor que possuo. Aqui, vou deixar em 100%.

Temos um menu superior com as informações principais, os dois menus principais e, dentro deles, alguns submenus, pelos quais vou passar um a um. Nas configurações, eu tenho a configuração de permissões e usuários, que é onde qualifico cada usuário com a sua permissão necessária. Dentro do grupo de usuários, temos os perfis e permissões. O sistema me abre aqui todas as telas e rotinas do módulo **Estoque**, e eu seleciono em quais vou ter permissão ou não.

Do lado esquerdo, ficam os usuários que têm essa permissão liberada e, do lado direito, os usuários que não têm essas permissões. Dentro de cada menu, temos todos os submenus com todas as telas do sistema, de modo que conseguimos fazer um controle bem rigoroso relacionado a permissões. Aqui seria, portanto, para a criação e configuração dos grupos de permissões.

Aqui eu consigo realizar a criação de novos grupos. Caso eu queira separar uma pessoa desse grupo de permissão, consigo criar um novo grupo. Se eu quiser criar um grupo novo e deixar apenas uma permissão para essa pessoa, não tem problema: eu posso criar um grupo novo, retiro aquela pessoa do outro grupo e a trago para este grupo aqui, com as permissões que eu configurar.

Temos, assim, essa parte de usuários e permissões. Em Usuários, de fato, o sistema me mostra todos os usuários cadastrados logo nessa primeira tela. Caso eu queira adicionar um novo usuário, basta clicar em "Adicionar", e o sistema abre as principais informações para a criação do usuário.

Em Negócios, é onde faço o cadastro de todos os produtos, fornecedores e tipos de distribuição. Primeiramente, temos a Categoria. Essa categoria normalmente é utilizada para **Papel de Segurança** e **Selos**, somente essas duas categorias. Não há necessidade de criar outra, mas, caso seja do desejo do usuário, também é possível através do botão "Adicionar". Preencho as informações necessárias e realizo o cadastro de uma nova categoria.

Em Fornecedores, caso eu queira deixar o fornecedor cadastrado de forma fixa para realizar a aquisição de **Selo** digital ou de **Papel de Segurança**, posso cadastrar um fornecedor fixo aqui. Clicando em "Adicionar", tenho os campos para preenchimento e posso realizar o cadastro desse fornecedor.

Seguindo, temos Grupos de Distribuição. No **ORION Estoque**, configuramos quais grupos de distribuição vamos utilizar no sistema. Posso adicionar um grupo de distribuição e, nele, escolher o tipo de distribuição: se desejo distribuir por máquina ou por usuário. Posso selecionar os usuários disponíveis para esse grupo ou, se for por máquina, vincular uma máquina disponível dentro dele. Assim, as distribuições realizadas para esse grupo de teste estarão disponíveis para essa máquina. Temos, portanto, essas duas opções.

Em Produtos, é onde cadastramos todos os produtos utilizados: desde cartão até certidões, **Papel de Segurança**, apostilamento, **Selo** de autenticação — todos os produtos existentes. O sistema apresenta uma primeira tela com todos os produtos já cadastrados, exibindo o que temos disponível em cada produto, o que está distribuído e o estoque mínimo, o qual cadastramos e configuramos com uma quantidade de alerta. Quando o sistema atingir essa quantidade (por exemplo, 400 cartões), ele emitirá um alerta avisando que atingiu essa margem para a realização de uma nova compra.

Aqui é onde realizamos o cadastro e a configuração de um produto. Clicando em "Adicionar", o sistema exibe os campos a serem preenchidos. Posso definir o tipo de **Selo**, a descrição, a unidade (se é unitário), o estoque mínimo (aquele alerta que mencionei quando atingir a quantidade definida) e o modo de distribuição desse produto. Se o produto for um **Selo** de autenticação, posso configurá-lo para distribuição para todos — assim, ao realizar a distribuição de **Selo** de autenticação, todos recebem esses **Selos**. Posso também configurar por escrevente (distribuindo uma quantidade separada para cada escrevente), por máquina, ou criar grupos de usuários ou de máquinas e destinar uma quantidade para cada grupo.

Na quantidade de atos, posso selecionar um ou dois, no caso de **Selos** com valor e sem valor. Em Código de Barras, preenche-se caso seja um **Papel de Segurança** (por exemplo, de um cartão de autógrafo / assinatura). O prefixo é a série do produto: consigo deixar esse prefixo cadastrado de forma fixa no produto para não precisar preenchê-lo a cada aquisição. Assim, sempre que fizer uma aquisição, o sistema já trará esse prefixo preenchido. Isso diminui a chance de o operacional realizar o cadastro de forma indevida, o que poderia impactar posteriormente na geração e comunicação do **Selo** digital.

Dessa forma, cadastramos o produto. Também é possível cadastrar o Tipo de Documento (como CPF e outros tipos de documento). Para cadastrar um novo tipo de documento, basta clicar em "Adicionar", preencher os campos e concluir. Temos também Unidade de Medida, onde costumamos trabalhar com "Unidade", pois controlamos a quantidade de **Selos** e de **Papel de Segurança** por unidade. Temos apenas uma cadastrada, mas nada impede o cadastro de um novo tipo, caso necessário.

Na parte de cadastros, temos todas essas opções. Em seguida, temos **Cartório**, que traz as informações gerais e todos os campos disponíveis com os dados da serventia. É onde ficam todos os dados do **Cartório**. E temos Modelos, onde cadastramos os modelos para impressão de relatórios dentro do **Estoque**.

Neste exemplo, não temos nenhum modelo preparado. Caso eu queira realizar a impressão de algum relatório, seria necessário cadastrar um novo modelo para permitir consultas, impressão de listagem de produtos, distribuição e assim por diante. É nessa tela que cadastramos todos os modelos do sistema.

Em Parametrizações, vemos que não estou com essa permissão liberada no momento, mas basta concedê-la para obter acesso. É onde realizamos a configuração de utilização do **Estoque**. Trata-se de uma rotina que nós mais utilizamos para configurar a serventia; normalmente, o **Cartório** não manipula muito essa aba, pois nela definimos os parâmetros de como os produtos serão utilizados (se de forma automática, manual, etc.).

Passando para a área de Administração, acessamos primeiramente a tela de Aquisição que, como o próprio nome indica, é onde realizamos a entrada de um produto. Após realizar a compra de um produto, fazemos a aquisição dele para dentro do sistema. Podemos informar o fornecedor e o número da nota fiscal (não obrigatórios), a data de aquisição e o comprador, registrando o nome de quem realizou o lançamento.

Vou realizar a aquisição de um produto: comprei aqui **Selos** de autenticação. O sistema já trouxe a série configurada de forma fixa, conforme cadastrado no produto, e aqui comprei da numeração 1001 a 2000, totalizando a quantidade de 1000 **Selos**. O valor unitário não é obrigatório.

Ao clicar em concluir, a aquisição é finalizada. Neste caso, o sistema acusou que já existia um cadastro com essa mesma numeração, então vou inserir uma sequência diferente: de 7000 a 7500. Cadastro realizado com sucesso! A partir desse momento, a aquisição realizada já está disponível para distribuição e uso.

Temos aqui a primeira tela de consulta e visualização, exibindo a aquisição efetuada e a quantidade disponível para distribuição e uso. Há um botão de registro para verificar detalhadamente quem realizou a aquisição e a distribuição, e um botão de visualização que abre a tela de aquisição para conferir o preenchimento realizado. Também é possível aplicar filtros para verificar se um usuário específico realizou distribuições.

Ao selecionar apenas o usuário "Editor", o sistema retornou as aquisições vinculadas a ele. Partindo para a tela de Distribuição, consigo realizar uma consulta para verificar se houve alguma distribuição realizada na data de hoje, por exemplo. Faço uma consulta por **Selo** de autenticação e filtro. Como não retornou nenhum resultado, acessamos a aba Distribuição, onde efetuamos a distribuição dos produtos.

Seleciono para verificar o que temos em **Estoque**. Consta a aquisição que realizei agora, de 7000 a 7500. Seleciono o item, clico na seta e o sistema preenche abaixo a série e a sequência selecionadas; em seguida, basta selecionar o portador. Vou selecionar como portador o usuário **ORION**. É possível realizar mais de uma distribuição por vez, então posso também vincular outra sequência e fazer a sua distribuição — esta segunda para o Bruno — e, por fim, clicar em concluir.

Os produtos foram distribuídos e não constam mais pendências de distribuição. Ao realizar uma consulta com o período de hoje, o sistema apresenta as duas distribuições efetuadas. Caso uma distribuição tenha sido feita erroneamente, basta selecioná-la e realizar o estorno: no mesmo instante ela sai dessa tela e retorna para o **Estoque**.

Ao realizar uma nova consulta nesta tela para o produto autenticação, ele já consta novamente disponível para distribuição. Dessa forma, conseguimos na mesma tela consultar as distribuições para realizar estornos, bem como efetuar novas distribuições.

Na tela de Consumo Manual, ao acessá-la, são exibidos todos os produtos disponíveis para consumo no momento — ou seja, todos os produtos que estão distribuídos —, permitindo realizar o consumo de forma manual. Vale destacar que possuímos integração entre o **ORION TN** e o **ORION Estoque**, de modo que o consumo é configurável para ocorrer de forma automática.

Assim, a cada serviço praticado, o sistema já realiza automaticamente o consumo da próxima sequência disponível. Contudo, também é possível realizar esse consumo manualmente: seleciono o produto desejado, indico o portador responsável pelo consumo e informo a quantidade.

Vou realizar o consumo de 10 autenticações na data de hoje. O sistema exibe as quantidades disponíveis e já traz a próxima sequência para consumo, totalizando os 10 itens selecionados. Posso definir o status como utilizado ou inutilizado e clicar em concluir. Essa tela serve, portanto, para efetuarmos o consumo ou a inutilização manual do produto.

Por fim, na tela de Consultas é onde geramos relatórios e consultamos o que há em **Estoque**, o que foi consumido ou utilizado, além de possibilitar inutilizar ou reutilizar **Selos** ou **Papel de Segurança**. Realizando uma busca simples com a data de hoje na categoria **Selos**, o sistema retorna tudo o que teve movimentação no dia.

Neste exemplo, constam cartões consumidos (1 cartão consumido) e 15 **Selos** de autenticação, sendo 10 consumidos e 5 inutilizados. A partir daqui posso imprimir o relatório — configurando previamente o modelo de impressão — e refinar os filtros de busca.

Selecionando **Selo**, posso escolher um tipo específico: buscando apenas por autenticação, por exemplo, o sistema oculta o cartão e traz somente os **Selos** de autenticação. Também é possível alterar o status para refinar ainda mais a consulta.

Posso buscar apenas por "Distribuído" ou por "Consumido" na data de hoje, trazendo exclusivamente o que foi consumido, ou filtrar por "Inutilizado", entre outros. Também consigo realizar a consulta detalhada — nesse caso, o sistema exige a seleção de um tipo de **Selo**.

Ao definir a categoria **Selos** e o tipo autenticação, o sistema solicita obrigatoriamente um status (como "Consumido", por exemplo). Na consulta detalhada, diferentemente da consulta resumida, são exibidas opções adicionais de ação para cada item.

Na consulta detalhada de hoje, foram localizados 10 registros de **Selos** de autenticação consumidos. Se eu desejar cancelar esses **Selos**, inutilizá-los ou retorná-los ao **Estoque** (no status "Distribuído") para consumo posterior, basta selecionar os **Selos** que desejo alterar.

Neste caso, vou inutilizar três deles e retornar os outros sete para "Distribuído", deixando a sequência novamente disponível para utilização. Ao refazer a consulta com o status anterior, aqueles registros não constarão mais da mesma forma, pois três **Selos** foram cancelados/inutilizados e os outros sete voltaram para distribuídos para consumo futuro.

Trata-se de uma tela de consulta completa, na qual é possível filtrar por múltiplos campos: tipo de status, série específica com sequência inicial e final, tipo de produto, categoria (**Papel de Segurança** ou **Selos**) e período. Caso não se saiba a data exata em que o **Selo** foi consumido ou cancelado, não há problema: basta realizar a busca informando apenas a série e a sequência que o sistema retornará a informação correspondente.
