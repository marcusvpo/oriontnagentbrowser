#### Descrição:
Apresenta o procedimento para lançamento e edição direta do valor previsto para o Registro de Imóveis no protocolo, utilizado quando o escrevente possui a estimativa calculada externamente ou deseja ajustar o valor sugerido de forma manual.

#### Passo a passo:
1. Na seção de custas do protocolo, localize o campo **Registro de Imóveis**.
2. Observe que o sistema exibe uma sugestão inicial de valor para o registro, estimada automaticamente sobre a base de cálculo informada.
3. Para utilizar o valor apurado externamente, clique no campo **Registro de Imóveis** e digite o valor monetário correto.
4. Pressione a tecla **Tab** para confirmar o valor.

* **Observação:** Se o campo **Registro de Imóveis** estiver travado/bloqueado para digitação manual, significa que o cálculo foi gerado através da tabela auxiliar de Registro de Imóveis (ícone de cifrão). Para liberar a digitação manual, é obrigatório acessar a tabela auxiliar, excluir todos os itens lançados e concluir com valor zerado.
---

* **Dica / Caso Real do 0800:** Caso o protocolo não seja localizado no Caixa, certifique-se de que o status do ato na triagem foi marcado como **Aguardando Pagamento** e verifique se o operador possui privilégios de movimentação financeira.
