#### Descrição:
O módulo de Escrituras para Registro do Orion TN 6.0 opera integrado via API ao ONR/SAEC, automatizando o envio de títulos notariais aos Cartórios de Registro de Imóveis. O sistema rastreia todo o ciclo de vida do registro imobiliário em 5 estágios padronizados (Encaminhado, Protocolado no RI com numeração automática, Devolvido com Exigência, Registrado e Entregue à parte).

#### Passo a passo:
1. No módulo **Notas**, acesse a aba **Protocolos** e abra a escritura lavrada que contenha o imóvel devidamente cadastrado.
2. No cabeçalho do protocolo, clique no botão **Encaminhar para Registro de Imóveis** (ou acesse o menu **Notas > Escrituras para Registro**).
3. Na tela de envio, confira os dados da serventia imobiliária de destino e certifique-se de que o **Traslado Digital em PDF** e os documentos correlatos (guias de ITBI, certidões) estão vinculados na aba **Anexos**.
4. Clique no botão **Transmitir via ONR** para enviar eletronicamente os dados e arquivos à central registral.
5. Acompanhe a evolução na tela de **Escrituras para Registro**: o sistema receberá via webservice o número da prenotação/protocolo do RI e mudará o status para **Protocolado no RI**.
6. Em caso de apontamento de pendência, o status mudará para **Devolvido com Exigência**, exibindo a íntegra da nota devolutiva; quando concluído, atualizará para **Registrado**, permitindo registrar a entrega formal à parte.

* **Observação:** O vínculo do número do protocolo do RI é realizado de forma 100% síncrona/automática através da integração da API, dispensando que o escrevente consulte e digite manualmente a prenotação externa.
* **Importante:** Caso ocorra alguma nota devolutiva, você pode sanar o apontamento no próprio Orion TN, anexar o aditamento ou certidão complementar e reenviar o título sem criar novo protocolo do zero.
---

* **Dica / Caso Real do 0800:** Evite o uso de aspas duplas, apóstrofos e quebras de linha manuais em campos de observações para comunicações com SISCOAF e CENSEC, prevenindo rejeições de schema XML.
