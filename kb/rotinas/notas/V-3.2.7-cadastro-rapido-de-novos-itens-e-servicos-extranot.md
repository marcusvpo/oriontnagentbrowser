#### Descrição:
Orienta o cadastro de novas modalidades de outros serviços e despesas extranotariais diretamente pelo botão de atalho na tela de custas. O cadastro é executado uma única vez e passa a ficar disponível para todos os usuários do cartório em atos futuros, permitindo definir se o item terá valor fixado por tabela ou valor livre para preenchimento no momento do ato.

#### Passo a passo:
1. Na seção de **Outros Serviços / Valores Extranotariais**, clique no botão **+** (Cadastrar Novo Item) localizado ao lado do campo de seleção de serviços.
2. Na tela de **Cadastro de Outros Serviços** que for exibida:
   * No campo **Descrição**, digite a nomenclatura completa do serviço (ex.: "Certidão de Casamento").
   * Para fixar um valor tabelado/padrão:
     * Digite o valor no campo correspondente (ex.: R$ 80,00).
     * Mantenha a opção **Sem valor fixo** desmarcada.
   * Para permitir que o escrevente digite o valor livremente a cada lançamento no protocolo:
     * Marque a opção **Sem valor fixo**.
3. Clique no botão **Concluir** para gravar o cadastro.
4. De volta à tela de custas do protocolo, selecione o novo item cadastrado na lista de sugestões.
5. Verifique o comportamento:
   * Se cadastrado com valor fixo, o sistema preencherá o valor automaticamente e travará o campo para edição direta.
   * Se cadastrado com a opção **Sem valor fixo**, o campo de valor unitário ficará aberto para digitação do valor desejado.

* **Observação:** O sistema não permite salvar o cálculo de custas se for digitada uma descrição manual avulsa diretamente no campo que não conste na lista oficial de serviços cadastrados. O cadastro prévio via botão **+** é mandatório para preservar a integridade do banco de dados.

* **Dica / Caso Real do 0800:** Na busca de atos no índice notarial, utilize o curinga `%` entre os nomes para localizar registros mesmo com variações ortográficas históricas de prenomes e sobrenomes.
