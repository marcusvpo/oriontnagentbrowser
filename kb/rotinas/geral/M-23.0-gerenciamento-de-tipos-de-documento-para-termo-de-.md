#### Descrição:
Ambiente de consulta e gestão dos modelos e tipos de documentos utilizados para gerar Termos de Comparecimento (CRV/ATPV-e veicular, Procurações, Declarações), permitindo editar regras e layouts.

#### Passo a passo:
1. Acesse o menu **Firmas > Termo de comparecimento > Tipos de documentos**.
2. Na listagem principal, visualize todos os tipos de documentos cadastrados na serventia.
3. Para localizar um modelo específico, digite o nome no campo **Pesquisar por descrição** (ex: 'CRV', 'Veículo', 'Geral') e clique em **Filtrar**.
4. Na linha do registro desejado, utilize as ações:
   * **Visualizar**: confere as variáveis, campos customizados e modelo de impressão vinculado.
   * **Editar**: altera textos fixos, obrigatoriedade de campos e parâmetros fiscais.
   * **Inativar**: desabilita o modelo para que não seja mais escolhido no balcão.
5. Para criar um modelo inédito, clique no botão **Adicionar**.

* **Observação:** Modelos parametrizados para comunicação com a SEFAZ possuem sinalização visual indicando o vínculo com a rotina de lotes CRV.
