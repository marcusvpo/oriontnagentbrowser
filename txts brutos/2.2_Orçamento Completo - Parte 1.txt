 Olá, nesse vídeo eu vou mostrar para você como realizar o cadastro completo de um orçamento de escritura e procuração. Para isso basta clicar no menu de notas e na opção de orçamento completo. Nessa tela os orçamentos realizados serão cadastrados no sistema, de modo que você consiga fazer busca dos mesmos posteriormente e gerar um ato ou um protocolo a partir desses orçamentos que ficarão aqui registrados. Nessa tela os campos que terão um asterisco são campos obrigatórios, de modo que se você não os preencher ao final do orçamento, que é esta opção de concluir, você não consegue concluir o orçamento se não preencher os campos obrigatórios, que estarão indicados aqui com um asterisco. Se você preencher aqui a espécie, ela estará condicionando o campo da natureza, por exemplo, se eu colocar aqui a espécie de escritura, você terá à disposição os tipos de escritura para serem cadastrados o orçamento aqui no seu cartório. Se você colocar aqui uma espécie de procuração, será listado no campo da natureza apenas as procurações disponíveis para o cadastro desse orçamento. Vamos fazer aqui então um orçamento completo, por exemplo, de uma escritura de compra e venda. O escrevente já estará preenchido automaticamente com base no último orçamento que foi realizado nessa máquina. Você terá a possibilidade de colocar o CPF ou CNPJ do solicitante que está solicitando este orçamento aqui no cartório. Este campo, pelo menos do nome do solicitante, ele é obrigatório para que você consiga fazer essas buscas posteriormente. Repare que ao lado desses campos, como do CPF do solicitante, você terá uma lupa. Esta lupa segue um padrão no sistema para você reaproveitar dados de um cadastro anterior. De qualquer parte do sistema onde é realizado um cadastro de pessoa, você poderá reaproveitar as informações, como por exemplo, o documento e até mesmo o nome do solicitante e os seus dados de contato como telefone, e-mail e endereços que são opcionais e facultativos aqui para o orçamento completo. Mas se eles já estiverem em algum cadastro que você está aproveitando, será preenchido automaticamente. Este preenchimento é apenas uma sugestão, você poderá alterar aqui as sugestões que o sistema trazer para você. Então por exemplo, se eu colocar aqui o solicitante Ricardo e clicar aqui na lupa, o sistema vai trazer para mim as opções que eu tenho para reaproveitamento dos dados de Ricardo, que é o que eu digitei aqui no campo do solicitante. Ele pode aproveitar os dados de um cadastro de solicitante que foi feito anteriormente, por isso que está aqui a opção de solicitante entre parênteses. Ou eu posso reaproveitar os dados de um protocolo que foi feito anteriormente. O sistema sempre vai listar o último protocolo ou o último solicitante que foi cadastrado. Ele poderá aproveitar os dados também do último cadastro de tomadores, que é do cadastro da nota fiscal eletrônica, assim como reaproveitar os dados do último cartão de assinatura que foi feito para essa pessoa. Após o solicitante ter sido na opção desejada, o sistema já vai trazer, se lá por exemplo, no cartão de assinatura desse nome que eu acabei de selecionar já estiver todos os dados de contato, ele já vai trazer preenchido aqui na tela. E você poderá alterar essas informações apesar da sugestão que está sendo feita. A tela do cadastro completo do orçamento já está sugerindo a você para que você selecione o ato ou a natureza das custas que você deseja. Para que você possa colocar a natureza desejada, você pode estar digitando a natureza que você quer e o sistema já vai sugerir ela aqui na barra de rolagem abaixo. Você pode selecionar ou então se você preferir, você pode deixar em branco o campo do item e dar um tab no seu teclado. E aí o sistema vai listar para você todas as naturezas disponíveis de modo que você pode dar um duplo clique e selecionar a natureza que você desejar aqui também. Vamos trabalhar aqui com uma escritura com valor declarado para esse orçamento completo. Perceba que o sistema já permite que você coloque a quantidade de cálculos que você deseja fazer o orçamento, assim como o cálculo ou o tipo do cálculo que você quer colocar. Então, por exemplo, o integral, aonde ele vai calcular o valor integral das custas, o valor da diligência, aonde ele vai dobrar o valor das custas, um terço, por exemplo, que vai calcular um terço dos valores das custas e assim sucessivamente. Vamos trabalhar aqui com o valor integral. E aqui no cadastro completo do orçamento, ele já vai ter a opção de você informar o valor venal e o valor do instrumento, aonde você digitando aqui o valor venal e sendo, por exemplo, o valor do instrumento maior do que o valor venal, perceba que o sistema já vai trazer para a base do cálculo o maior valor entre eles, entre o valor venal e o valor de instrumento, ele já vai trazer automaticamente para a base de cálculo. Nada impede que você faça uma digitação manual desse valor base do cálculo, apesar da sugestão que é feita aqui. E aí parcialmente o sistema já traz para você aqui o valor do ato notarial, com base no valor base de cálculo que está aqui. Você terá a opção também no seu cartório de deixar uma cidade padrão para que o sistema traga uma alíquota padrão, aonde você digitando essa cidade, o sistema já vai trazer para você alíquota padrão. Ou você pode estar digitando alíquota padrão e o sistema já vai calcular aqui para você. Tanto o valor base de cálculo para a ITBI já pode vir com alíquota padrão ou você pode estar digitando, mas também o valor de registro ele já vem com o valor padrão do registro de imóveis, com base no valor base de cálculo que foi digitado aqui. Você vê que esse valor que está sendo sugerido aqui é apenas o valor de registro. Se você deseja adicionar a esse valor outros valores além do registro de imóveis como o valor de prenotação, como o valor de certidões, você poderá fazer uso da opção aqui da tabela do registro de imóveis, que é esse cifrãozinho aqui do lado. Se você clicar nesse cifrãozinho aqui, o sistema vai abrir uma tela nova aonde você poderá adicionar os valores de certidão do registro e ele já vai trazer aqui para você como padrão o valor de certidões, você pode colocar aqui por exemplo duas certidões que você quer adicionar ao seu cálculo, ele já traz aqui o valor. Você pode estar mudando a cidade e o percentual aqui, que o sistema já vai calcular de acordo com a cidade e o percentual do ISS, o valor para aquela natureza do registro de imóveis que você deseja. Se você quiser acrescentar aqui outros valores como por exemplo uma averbação, basta clicar aqui no sinalzinho de mais para adicionar um ato e aqui você digita, se você já souber o item você pode digitar o código ou se você não souber se digita aqui a descrição o sistema já vai trazer aqui por exemplo uma averbação com valor declarado aonde você consegue aqui ter o valor já preenchido e a quantidade você pode estar trabalhando com ela aqui também. Se você quiser adicionar o valor de prenotação também, o sistema já vai trazer aqui para você o valor da prenotação. E aqui ele já fez com base na tabela do registro de imóveis todo o cálculo do registro. Ele já traz aqui para você um panorama. Quando você clicar aqui em concluir o sistema já vai falar para você que a soma desses valores é diferente da soma que já existia lá naquele campo do registro de imóveis. E o sistema pergunta se você quer atualizar o valor, você fala que sim, ele já vai trazer o valor que você calculou lá.
