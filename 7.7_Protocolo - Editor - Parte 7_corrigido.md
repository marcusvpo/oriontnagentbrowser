Bom, para finalizar aqui agora o editor, vou mostrar aquele segundo cenário onde o **Cartório** pode utilizar os modelos confeccionados dentro do sistema. Nesse caso, toda a qualificação é feita dentro do sistema, no cadastro do protocolo, para que você possa utilizar os modelos criados internamente. Reforçando o que já mencionei: para que isso aconteça, o **Cartório** precisa encaminhar os modelos desejados à nossa equipe comercial para avaliação, para que possamos criá-los e disponibilizá-los no sistema. Alternativamente, o **Cartório** pode avaliar os nossos modelos padrão para verificar se atendem às suas necessidades e passar a utilizá-los.

Para que funcione dessa maneira, como disse, toda a qualificação passa a ser realizada no protocolo. Você precisará preencher todos os campos necessários para qualificar as partes, aproveitando recursos como a busca por CPF na lupa, a importação de dados do cartão de assinatura ou de um protocolo anterior, garantindo a qualificação completa com o menor esforço possível antes mesmo do uso da IA. Ou seja, você precisará cadastrar toda a qualificação das partes no protocolo; caso contrário, não será possível visualizar esses modelos prontos no editor.

A mecânica operacional funciona da seguinte forma: antes de acessar o editor para inserir os modelos, você precisa qualificar o texto. Qualificar o texto não significa apenas preencher os campos de cadastro — dados da parte, dados do **Cônjuge** e demais informações que você já salvou. Para qualificar o texto, você clica no botão "Qualificação", localizado ao lado da parte. Ao clicar, o sistema carregará um modelo padrão previamente configurado para o seu **Cartório** (como o modelo de solteiro, por exemplo), trazendo a redação exata exigida pelo **Cartório** e destacando em vermelho os campos que não foram preenchidos no protocolo. Esse texto é o que comporá o modelo da sua escritura pronta dentro do sistema, sendo necessário salvá-lo nesta etapa.

Alguns **Cartórios** que não utilizam nossos modelos prontos aproveitam essa rotina para extrair o texto de qualificação: uma vez preenchidos os dados no protocolo, eles copiam o texto gerado aqui e colam na escritura em um editor externo, o que também é perfeitamente viável. Contudo, a finalidade principal é que essa qualificação alimente diretamente os modelos prontos do sistema. As informações destacadas em vermelho indicam dados ausentes que devem ser preenchidos no protocolo.

Você pode se perguntar se não seria possível digitar diretamente na tela de qualificação. O sistema até permite a digitação — por exemplo, se a UF do órgão emissor do documento de identidade ou CNH não estiver preenchida, você pode inseri-la manualmente —, mas isso deixará o protocolo desatualizado. Existe inclusive um parâmetro no sistema que bloqueia a digitação direta nessa tela, cabendo ao **Cartório** decidir se deseja ativar esse bloqueio. O recomendável é manter a trava ativa para assegurar que a base de dados do protocolo esteja sempre completa.

Demonstrando o fluxo correto: vou fechar a tela sem salvar e retornar ao documento para preencher o campo pendente com "SP" e salvar. Nesse momento, o sistema atualiza o índice do protocolo. Ao retornar à tela de qualificação da parte, você notará que, inicialmente, a alteração não aparece, pois o sistema mantém o texto gerado anteriormente. Sempre que você alterar informações no protocolo, deve clicar no botão "Remesclar". O sistema atualizará o texto conforme os novos dados do protocolo, eliminando as pendências em vermelho. Sem destaques em vermelho, você tem a certeza de que a qualificação está perfeita e sem falhas no índice ou no texto; então, basta salvar.

Outro detalhe: caso você precise alterar o modelo de qualificação (por exemplo, mudando de solteiro para casado), basta acessar a barra lateral na aba da lupa. Ali ficam listadas todas as opções de qualificações disponíveis para o seu **Cartório**, confeccionadas previamente pela nossa equipe. Você pode clicar no ícone do "olho" para abrir uma pré-visualização em modo somente leitura, conferindo a estrutura do texto antes da inserção e identificando eventuais campos em vermelho para ajuste no protocolo.

Se estiver tudo correto, você pode inserir o modelo clicando diretamente sobre ele na listagem. O sistema perguntará se você deseja incluir (adicionar ao texto existente) ou sobrescrever o conteúdo atual. Ao optar por sobrescrever com o modelo de casado, o sistema carregará os dados e a qualificação do **Cônjuge**, apontando em vermelho o que ainda estiver pendente.

Mantendo o modelo de solteiro como exemplo: como meu usuário possui permissão para edição direta pelo escrevente, ajusto a informação necessária e clico em salvar. O texto de qualificação do outorgante fica devidamente registrado. O mesmo procedimento deve ser repetido para todas as partes envolvidas no ato (como a outorgada Cláudia, salvando a sua respectiva qualificação).

Essa mesma sistemática de pré-qualificação aplica-se aos imóveis. Antes de abrir o editor, acesse o cadastro do imóvel e clique no ícone "A" (Azinho) para abrir a pré-qualificação imobiliária. O sistema disponibilizará modelos predefinidos na lupa conforme o tipo de imóvel cadastrado no **Cartório**, permitindo pré-visualizar, editar (caso autorizado pelas permissões da serventia) e carregar a descrição correspondente. Ao clicar em salvar, o imóvel estará pré-qualificado. Dessa forma, conclui-se a pré-qualificação completa dos outorgantes, outorgados e imóveis antes da etapa de edição da minuta.
