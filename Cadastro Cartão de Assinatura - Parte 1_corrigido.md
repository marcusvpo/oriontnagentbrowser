Olá! Eu vou mostrar para você, neste vídeo, como realizar o cadastro de um novo cartão de assinatura. Para isso, basta acessar o menu de **Firmas**, selecionar a opção "Cadastros" e clicar em "Cartão de Assinatura". Na tela de cartões de assinatura, basta clicar na opção "Adicionar". Pronto: o sistema disponibilizará os campos para o cadastro do novo cartão de assinatura. Perceba que alguns campos já vêm com um asterisco ao lado, indicando preenchimento obrigatório. Por padrão, o sistema define como obrigatórios o nome e o CPF. Enquanto esses campos não forem preenchidos, o sistema não habilitará o botão "Concluir" logo abaixo para efetivar o cadastro do novo cartão. Outros campos podem ser configurados como obrigatórios de forma opcional.

Para agilizar o preenchimento do seu novo cartão de assinatura, você poderá utilizar a busca ao lado do campo de nome, reaproveitando dados já cadastrados anteriormente no sistema. Também é possível utilizar a lupa ao lado do campo do CPF para uma busca mais exata. Se desejar reaproveitar os dados de um nome ou CPF existente, basta digitar a informação no campo correspondente e clicar na lupa para que o sistema exiba os resultados encontrados.

Caso selecione um resultado identificado com "(Protocolo)" entre parênteses, serão reaproveitados os dados do índice de escritura e procuração referentes ao último protocolo cadastrado para aquele nome ou CPF. O mesmo se aplica ao cartão de assinatura: o sistema sugerirá sempre o último cartão preenchido para o nome ou CPF pesquisado. Ao selecionar a opção desejada (como o último cartão de assinatura), o sistema exibirá uma mensagem de confirmação para a importação dos dados. Basta confirmar para carregar as informações, ficando todos os campos abertos para eventuais alterações necessárias neste novo cadastro.

Note que o campo de profissão também possui uma lupa de busca. Isso é fundamental porque, caso você digite uma profissão inexistente no cadastro e pesquise, o sistema não retornará nenhum resultado. Se você tentar salvar o cartão com o texto digitado sem selecioná-lo a partir da busca, a profissão não será gravada na ficha. Caso a profissão não conste na busca, basta copiar o termo digitado (Ctrl+C), clicar no botão de mais (+) para cadastrar a nova profissão e concluir. Feito isso, a profissão passará a constar na busca e será vinculada corretamente ao novo cartão.

Esta tela de cadastro é dinâmica: conforme as informações são inseridas, novos campos são habilitados. Por exemplo, os dados do **Cônjuge** só serão exibidos se o estado civil selecionado for "Casado"; caso permaneça como "Solteiro", os campos do **Cônjuge** sequer são exibidos. Essa dinâmica assegura o preenchimento correto e estruturado do cartão de assinatura.

Para documentos como o RG, você pode anexar uma digitalização ou capturar uma foto diretamente pela webcam, vinculando-a ao cadastro — funcionalidade também disponível para a CNH. Adicionalmente, todos os campos acompanhados pelo ícone informativo ("i") exibem explicações detalhadas ao posicionar o mouse sobre eles.

Você também pode adicionar múltiplos tipos de contato: clicando no botão de mais (+), é possível cadastrar tanto um e-mail comercial quanto um e-mail pessoal (ou remover pelo botão de menos, se necessário). A mesma regra se aplica aos telefones (residencial, comercial etc.), com a possibilidade de marcar um deles como "Principal" para priorização nas telas do sistema. O cadastro de endereços segue o mesmo critério, permitindo definir o endereço principal e incluir novos tipos de endereço conforme a necessidade.

Se a pessoa cadastrada representar uma empresa (pessoa jurídica), basta clicar no botão de mais (+) na seção correspondente, inserir o nome da empresa e o CNPJ (obrigatório) para efetuar o vínculo. É possível também defini-la como padrão caso haja múltiplas empresas vinculadas, sendo que essa informação constará no termo de comparecimento.

No painel lateral direito, estão disponíveis os recursos de captura de imagem: foto da pessoa pela webcam, coleta biométrica (posicionando a digital no leitor biométrico configurado e concluindo) e inclusão da imagem do cartão de assinatura. Para o cartão, você pode importar um arquivo já digitalizado de uma pasta do Windows, capturar diretamente via scanner selecionando o periférico instalado ou tirar uma foto do cartão preenchido manualmente pela parte. Em todas as opções de captura (pasta, scanner ou foto), é indispensável clicar em "Concluir" para efetivar o vínculo da imagem à ficha.

Para finalizar o cadastro, basta clicar no botão "Concluir". Se houver campos obrigatórios pendentes ou alguma inconsistência (como uma data de nascimento inválida), o botão permanecerá inativo e o sistema exibirá um triângulo de alerta. Basta verificar o campo indicado, corrigir a inconsistência e o botão "Concluir" será habilitado imediatamente para finalização do cadastro.

Esta foi a primeira parte do cadastro de um novo cartão de assinatura. No próximo vídeo, veremos o consumo do papel de segurança, a aplicação do **Selo** digital, a edição de fichas e a inclusão de novos cartões de assinatura diretamente na tela de reconhecimento de **Firma**.
